# SmartDesk - E-Learning Platform 📚🎓

**SmartDesk** is an interactive e-learning platform that provides students with access to high-quality educational content, online courses, and study materials.

## 🌟 Features
✔️ User Registration & Authentication  
✔️ Video Lectures & Study Materials  
✔️ Live Coding & Interactive Quizzes  
✔️ MongoDB Database for Storing Student Progress  
✔️ Responsive UI with Modern Design  

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT (JSON Web Tokens)  
- **Deployment:** (Optional: GitHub Pages, Heroku, or Vercel)

### 1️⃣ Clone the Repository
